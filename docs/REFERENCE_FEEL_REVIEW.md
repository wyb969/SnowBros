# 按画面宽度归一化的手感校准

依据：用户在 2026-11-10 提供的汇总表。表中链接指向用户电脑 D 盘，当前云环境无法读取这些图片；本轮采用表内测量与证据边界，没有声称重新看过对应图像或 21 分钟处的原片。

逻辑画面宽度为 960，所有 W 均指这一逻辑宽度，和设备分辨率、Retina 倍率无关。下列实现数值是拟合起点；截图样本不能独立证明起步 / 转向延迟、精确抗雪次数、所有墙面反弹规则或完整雪球寿命。

## 雪片先快后缓

此前较明显的上扬曲线已经收小，改用本轮更明确的样本规律：初段快速近似平射，末段主要是水平减速，再叠加轻沉。

- 普通雪片快速段 0.10 秒，黄色强化快速段 0.20 秒，之后均有 0.20 秒减速段。
- 减速段速度按连续曲线从初速降至 12%，位置直接使用这条速度曲线的积分。改变帧率不会改变射程，也不会把减速错误做成反向运动。
- 当前普通 / 黄色总射程约为 314 / 502 px，总飞行时间约为 0.30 / 0.40 秒；这些范围是本轮调参，不是截图锁定值。
- 末段下沉先短暂柔和进入，再接近恒定沉降速度，没有从出手套用人物重力。末尾保留最多 0.8 px 微扰与约 3.7° 摆角。
- 蓝瓶仍扩大雪片并增强积雪效果；黄色仍增加雪片长度和射程。已发出的雪片保持自身发射参数。

样本没有给出末段测量起点相对于整段飞行的位置，因此没有逐点强配 7、5、4、2、2 这五个数；目前对齐的是初速量级、末段明显递减、最后约两像素横移，以及小幅稳定下沉。

## 攻击状态和接触类型

- 发射保留独立的雪片数组，多发雪片可同时飞行；命中结算积雪，部分覆雪与完整雪球保持独立状态。
- 闪色是表现，不作为命中计数器；当前六次普通积雪满球仍是工程占位强度，不视作原片已确认次数。
- 完整球继续保持实体、慢推、重叠、站立与顶起；远处雪片不会把它踢出，近身攻击才开始高速滚动。
- 撞普通敌人、失去支撑、落到下层、撞侧墙分别处理。撞敌后滚球继续运动，同一目标只给分一次；离台后转入下落，遇到沿途首个承接平台继续滚。
- 侧墙处理已独立成关卡边界策略；现有上层反弹、底边出场、15 次上限仍是临时规则，不从这些样本推断所有墙面都一致。

没有根据稳定步速样本添加自行猜测的起步或转向帧数；当前方向输入继续即时响应。红瓶维持额外移动与推球强化，倍率暂未由这些图像确认。
