# 一分钟录像分析与本轮复刻范围

来源：用户上传 `DlVMfC2Bm4M_00m00s-01m00s.mp4`。时间戳从片段起点计算，片长 60.000 秒，1234×1080，60fps。

先以每秒一帧浏览全片，再对 00:09–00:22 以 8fps、00:17.350–00:17.950 以 30fps、00:48–01:00 以 3fps 细查。时间范围按画面事件标注，非原始输入记录；细查关键球碰撞时间误差约一个抽样间隔（33ms）。

## 版本与边界

片中有 TOAPLAN 1990、CREDIT 0、PLEASE INSERT COIN，内容是街机版待机教学与 Boss 演示。它不是 FC 第一关实战。本工程仍以用户要求的 FC 第一关为目标，本轮参考两版共有的动作；FC 操作定义另由 NES 原说明书核对。

录像能证明动作结果，不能直接证明按键时刻、碰撞体形状、摩擦系数、精确命中次数或 FC 数值。不要把调参值表述成原版测量结果。

## 已确认、补充依据与未知内容

- 录像确认：完整雪球可站立、可慢推、可踢成高速滚球，两个球碰撞后仍分别存在，角色能随球滚动；攻击有朝向和阶段反馈，强化有文字和弹体变化。
- NES 原说明书确认：方向键推球；推球时 B 踢出；在球下 A 跳跃可把球顶起；随雪球移动时 A 可跳出。录像中没有足够清楚、独立的头顶球样本，不能把它误写成视频测量结果。
- 未确认：第一关准确布局和敌人数量、FC 精确移动 / 跳跃数值、精确减速曲线、每种碰撞的恢复系数、雪球完整寿命及全部奖励条件。
- 特别修正：之前的“撞敌损失 39% 动能、撞墙保留 65% 速度、18 秒超时碎裂”属于自行设定，无法由本片支持。新版以明显更弱的减速和状态交互为重点。

## 本轮实施项

1. 完整雪球实体：侧向阻挡、慢推、顶部站立、头顶上抛。
2. 攻击方向与接触判定；推球、踢球分别处理。
3. 两球实体碰撞及传播滚动，保留两球，角色能随滚球移动并跳出。
4. 弱衰减滚动，避免每次碰撞产生夸张减速。
5. 命中闪色、分数浮字、红 / 蓝 / 黄强化及即时提示。
6. 加入可直接进入的交互练习场，复现上述动作，不必每次从头冻结。
