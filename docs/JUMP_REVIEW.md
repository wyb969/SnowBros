## 2026-11-04 的修改记录

- 旧代码以固定 0.5 秒转完 360°，旧物理同高度往返约 0.98 秒，导致下降后半程直立和滞空偏长。
- 起跳速度从 490 调为 700 px/s，玩家重力从 1000 调为 2000 px/s²。理论同高度往返从 0.98 缩到 0.70 秒，理论跳高从 120.05 变为 122.5 px；120Hz 碰撞步进下实际约 120 px，仍可跳上相差 108 px 的平台。这是当前工程的手感校准，并非测得的 FC 常量。
- 上升接近最高点时转过前半圈；下降根据预计接触的平台或球顶，连续完成剩下的半圈。角度只向前推进，不因空中改方向而倒转，也不超过一圈。实际碰撞决定落地。
- 同一套起跳参数用于地面、球顶和跳出滚动雪球；自然坠落不翻转。
- 普通雪弹让未完全冻结的敌人原地定身并累积雪量，不添加任何水平或向上的击退。已经离地的目标继续原有纵向运动和重力；滚球击败敌人后的抛飞是另一状态。

## 侧身、透视收缩与多指输入打磨

按用户进一步反馈，保留这一轮已经接近参考的跳跃节奏，补充空翻表现与摇杆回中修复：

- 一圈采用八个朝向阶段：正面、前三分之四、侧面、后三分之四、背面，再从另一侧转回。背面隐藏眼睛和鼻子、改画背部交叉背带；两侧朝向显示不同的肢体遮挡。
- 侧身时身体收窄，倒置时收腿，手臂向膝部靠近。绘制宽度最低约为起跳姿态的 74%，高度最低约为 82%，随后恢复。缩放连续变化，保持角色可辨认；碰撞与跳跃速度沿用上一版。
- 摇杆旧版只依赖控件接收 Pointer Events 的松手事件，存在事件改投页面其他位置后未清理的缺口。新增页面捕获阶段的松手、取消和丢失捕获清理，鼠标松开后移过页面也可纠正残留。
- Safari 使用原生 Touch Events 和独立的触摸 ID，避免和兼容 Pointer Events 重复记账。对照每次事件的当前触摸列表，清理已经消失的手指；摇杆松开不影响另一只手持续喷雪。
- 转屏、视口变化、切后台与设置开关都会回中并清除控件捕获；第二根手指不能接管已经按住的摇杆。

新增回归模拟滑出控件、漏松手、触摸 ID 连续复用 100 次、交替松手、三指操作和触屏编辑布局。总计 131 项逻辑与模型检查通过；另外执行左右方向共 128 次原生绘制回调，未出现脚本或绘制错误。没有可用浏览器 QA 工具，尚未在 iPhone Safari 实机复测该偶发问题。
